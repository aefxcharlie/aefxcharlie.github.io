## 🎮 Game Development

Game development is my main focus. I'm working in **Unity 6** with **C#**, learning the craft one system at a time:

- **2D game development:** building games in Unity with mechanics that feel right and run well.
- **Gameplay programming:** player controllers, physics and collisions, and the `MonoBehaviour` lifecycle.
- **Scenes & prefabs:** structuring GameObjects, prefabs and scene hierarchies so projects stay clean as they grow.
- **Polish & optimization:** treating game feel and performance as part of the mechanic, not an afterthought.

I'm always looking for the next mechanic to prototype, the next system to understand properly, and the next build to ship.
